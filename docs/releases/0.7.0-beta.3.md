Yog 0.7.0-beta.3 — fixes found playing on a Forge 1.19.2 modpack and server, and new client primitives.

## Fixes

- **Mirrors of block boxes on servers with negative coordinates.** A `u64` crossing the bus lost everything from 2^63 up, so every block position with a negative x failed its whole frame and block boxes never got rows (bots couldn't find their way). Unsigned numbers keep all 64 bits now; the bus arena is 4 MB, and a box's keys are asked in parts and again when some get no row.
- **Nanites on this client's entities.** An entity a nanite handed back was found again by its uuid on the server: on a remote server each call failed, in singleplayer it reached the server's twin. A client-side entity stays the client's; a missing object is reported by member and reference.

## New

- `client::only_blocks` — draw only the chosen blocks, every other one unseen and seen through (works with Sodium/Rubidium).
- `item::Food` — what eating an item gives, as the game says, on every version: nutrition, saturation, effects and whether each is beneficial.
- Releases are built by CI on a version's tag: every loader × Minecraft version, all five platforms, and the runtime's debug symbols.
