Yog 0.7.0-beta.4 — the bus and every Yog file on Substrate Data, saved and synced state for mods, and a big step for Yog Script. A test release: mods built on yog-api 0.109 need it.

## Breaking

- **ABI 6.0.** The bus speaks Substrate Data (SDAT version 2); a mod built for 0.7.0-beta.3 (ABI 5) doesn't load — rebuild it on yog-api 0.109.
- **Yog Data is Substrate Data.** Every `.ydata`, block, item, recipe, book and resource is written as SDAT version 2; version 1 files (and the old YOGD) are still read, never written. The Java hosts read and write it through Substrate Data's Java port (Java 17+).

## New

- **Mods' state, saved and synced** — saved members on the mod, `extend Player`/`World`, blocks, entities and the held item stack (records, enums with data, nullable values, lists, dictionaries, text); synced members the server writes and clients read; `was` migrations for saved members. Rust has the same: `ItemData`, `EntityData`, `BlockData`, synced kept values.
- **Commands** — the sender's permission level and op flag (`Sender.IsOp`, `CommandContext`).
- **Yog Script** — content, blocks' and items' members, client and server sides with messages, commands, events, `async`/`await`, iterators, LINQ and query syntax, generics kept at run time, `ref`/`out`, every pattern, records, tuples, expression trees, Reflection, logging as .NET's, ownership and threading primitives, and .NET's collections, numbers, text and time in its System library.
- **Files checked as they're edited** — a block's, item's, model's, states' and recipe's own rules (fields that don't go together, a template beside elements, placement without facing…) live in `yog-formats` and are reported by the IDE's live check, not only at build.
- `yog data check <file>` — what the IDE's live check says about a file.
- A mod's main language (`yog.toml`), and `yog new` in it; a mod without Rust still builds its native part.

## Fixes

- A mod's generated `Cargo.toml` names the exact Substrate Data version (a mod's lock could keep an older one).
- The bus' records only ever gain fields at their end.
- GameLog on SLF4J 1 (Minecraft 1.19.2).
